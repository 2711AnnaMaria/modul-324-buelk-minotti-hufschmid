# Development Standards

## Entwicklungsumgebung

* Wir verwenden **IntelliJ IDEA** als IDE.
* Alle Teammitglieder verwenden die im Projekt definierten Dependencies und Konfigurationen.
* Abhängigkeiten werden über `package.json` und `package-lock.json` verwaltet.

## Code Formatting & Linting

* **Prettier** wird zur Formatierung verwendet.
* **ESLint** wird für Linting und Codequalität verwendet.
* Code wird vor dem Commit formatiert und gelintet.

## Testing

* **Vitest** für Unit- und Funktionstests.
* **Playwright** für UI- und E2E-Tests.
* **Wireit** für die Ausführung der E2E-Testumgebung.
* Neue Funktionalitäten werden sinnvoll getestet.

## File Structure

* Wir orientieren uns an den **Angular-Konventionen**.
* Zusammengehörige Dateien werden gemeinsam organisiert.
* Einheitliche und nachvollziehbare Dateinamen werden verwendet.
* Neue Strukturen werden bei Bedarf im Team abgestimmt.

## Plugins & Dependencies

Verwendete zentrale Tools:

* Angular
* IntelliJ IDEA
* Prettier
* ESLint / Angular ESLint
* Vitest
* Playwright
* Wireit

Neue Dependencies werden nur hinzugefügt, wenn sie tatsächlich benötigt werden.

## Teamstandard

Alle Teammitglieder halten sich an diese Standards. Änderungen an den Standards werden gemeinsam besprochen und beschlossen.
